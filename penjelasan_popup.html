DOKUMENTASI TEKNIS FITUR POP-UP FOTO PIN LOKASI

Aplikasi Android SpotKu • Presentasi & Penjelasan Kode

Dokumen ini menjelaskan secara teknis dan mendalam mengenai implementasi Fitur Pop-Up Preview Foto dari Pin Lokasi Peta pada aplikasi SpotKu yang ditulis menggunakan Flutter dan OpenStreetMap (flutter_map).

1. KONSEP UTAMA (STATE MANAGEMENT)

Fitur pop-up ini dikontrol menggunakan mekanisme State Management lokal berbasis StatefulWidget pada berkas lib/screens/home_screen.dart.

Variabel penentu utama ditaruh pada state kelas _HomeScreenState:

Spot? _selectedSpot; // Menyimpan data spot yang sedang di-klik (bernilai null jika tidak ada)
  • Jika _selectedSpot == null: Tidak ada kartu pop-up yang ditampilkan di atas peta.
  • Jika _selectedSpot berisi objek Spot: Kartu pop-up pratinjau gambar akan dirender melayang tepat di atas koordinat lokasi tempat tersebut.
2. ALUR KERJA INTERAKSI PENGGUNA
[ Pengguna Mengetuk Pin Merah di Peta ] │ ▼ [ 1. setState() mengisi _selectedSpot dengan data tempat tersebut ] │ ▼ [ 2. Warna Pin berubah dari MERAH menjadi BIRU ] │ ▼ [ 3. Layer ekstra (MarkerLayer) menggambar Pop-Up Foto di atas Pin ] │ ├──────────────────────────────────────────────┐ ▼ ▼ [ Jika Pop-Up Foto Diklik ] [ Jika Area Kosong Peta Diklik ] │ │ ▼ ▼ [ Pindah ke Layar DetailScreen ] [ _selectedSpot diubah jadi null ] │ ▼ [ Pop-Up Tertutup ]
3. BEDAH KODE RINCI (HOME_SCREEN.DART)

A. Deteksi Sentuhan Pin & Perubahan Warna (Baris 112–128)

GestureDetector( onTap: () { // Simpan data spot yang diklik ke _selectedSpot setState(() { _selectedSpot = spot; }); }, child: Icon( Icons.location_pin, // Ubah warna pin yang aktif dari Merah menjadi Biru color: _selectedSpot?.id == spot.id ? Colors.blue : Colors.redAccent, size: 40, ), )

B. Menggambar Kartu Pop-Up Melayang (Baris 187–247)

if (_selectedSpot != null) MarkerLayer( markers: [ Marker( point: LatLng(_selectedSpot!.latitude, _selectedSpot!.longitude), width: 140, height: 140, child: Align( alignment: Alignment.topCenter, child: GestureDetector( onTap: () { // Pindah ke DetailScreen saat kartu pop-up disentuh Navigator.push( context, MaterialPageRoute( builder: (_) => DetailScreen(spot: _selectedSpot!), ), ); }, child: Container( margin: const EdgeInsets.only(bottom: 24), // Melayang di atas pin width: 120, height: 90, decoration: BoxDecoration( color: Colors.white, borderRadius: BorderRadius.circular(12), boxShadow: const [ BoxShadow(color: Colors.black26, blurRadius: 6, offset: Offset(0, 3)), ], ), child: ClipRRect( borderRadius: BorderRadius.circular(12), child: _selectedSpot!.mediaType == 'image' ? Image.file( File(_selectedSpot!.mediaUrl), // Gambar dari penyimpanan HP fit: BoxFit.cover, ) : const Center(child: Icon(Icons.videocam, size: 40)), ), ), ), ), ), ], )

4. CARA MENJELASKAN KEPADA DOSEN
Poin Presentasi:
"Fitur pop-up gambar ini dikontrol oleh variabel state _selectedSpot di HomeScreen. Saat pengguna mengeklik salah satu pin merah di peta, setState() menyimpan data tempat tersebut dan mengubah warna pin menjadi biru. FlutterMap kemudian merender layer Marker tambahan berupa kartu Container melayang yang menampilkan pratinjau foto dari file memori HP (Image.file). Jika kartu foto diklik, aplikasi membuka DetailScreen. Apabila area kosong pada peta diklik, _selectedSpot diubah menjadi null untuk menutup pop-up secara otomatis."
